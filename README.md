# 🔐 AES Encrypt / Decrypt Web Tool

Một công cụ web đơn giản để **mã hóa (encrypt)** và **giải mã (decrypt)** văn bản bằng thuật toán **AES-GCM** sử dụng Web Crypto API, không cần thư viện ngoài như CryptoJS.

## 🚀 Tính năng

- ✅ Giao diện hiện đại, responsive (dùng Bootstrap 5)
- ✅ Mã hóa / Giải mã hoàn toàn phía client (an toàn, không gửi dữ liệu ra ngoài)
- ✅ Cho phép **nhập tay hoặc tải lên file .txt**
- ✅ Tải kết quả đầu ra sau khi mã hóa/giải mã
- ✅ Không cần server, chạy trực tiếp bằng trình duyệt

## 🛠️ Cách sử dụng

1. Tải file về hoặc mở trực tiếp trong trình duyệt.
2. Nhập văn bản cần mã hóa hoặc chọn file `.txt`
3. Nhập khóa bí mật (ít nhất 1 ký tự)
4. Bấm nút "Mã hóa" hoặc "Giải mã"
5. Sao chép hoặc tải kết quả về
